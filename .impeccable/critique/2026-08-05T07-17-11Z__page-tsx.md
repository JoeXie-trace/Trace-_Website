### Design Specificity Verdict

页面整体有明确的产品性格：宋体衬线大标题、纸白/墨黑/品牌红的暖调、剧本排版意象，是「为写作工具而生」的设计，不是可替换的模板。唯一明显「模板化」的一处是打赏区——它与功能区卡片共用卡片语法，缺少动作语义。

机械检测器：`detect.mjs --json app`（含 app/page.tsx）两次扫描均 0 条发现、exit 0，无 advisory。浏览器可视化不可用（本会话无特权 node_repl/浏览器通道，浏览器客户端拒绝：Browser use requires privileged node_repl capabilities），无 overlay，以下为源码级审查。

### Overall Impression

底子很好——温暖、克制、有文学气质。最大的机会在打赏区：它现在更像「装饰性卡片」而不是「动作」。把它从卡片改成明确的按钮（或带动作文案的紧凑卡片），整页的转化意图会立刻清晰。

### What's Working

1. 统一且独特的视觉语言：纸白/墨黑/品牌红 + 宋体衬线，功能区、灵感区排布有呼吸感，气质贴合写作软件。
2. 打赏区语气：先「永久免费」降低防备，再用条件句「如果它帮你写完了一个故事」柔化索取感，配合 ☕，情感上优雅、不压迫。
3. 细节用心：lang=zh-CN、全部 img 有 alt、reduced-motion 支持、弹窗 Esc/背景/× 三路关闭 + 滚动锁定。

### Priority Issues

**[P1] 打赏卡不可点击感**
- What：260px 高半透明大色块 + 52px 咖啡 emoji + 一句感谢语，与页面其他卡片（功能卡、二维码占位卡）视觉同构；无按钮形态、无动作文案、无箭头等提示。
- Why：用户从整页学到「卡片≠可交互」，会直接跳过；这正是「不知道可以点击」的来源。
- Fix：把动作说出口——卡片上给出明确动作行（如「扫码请我喝一杯咖啡」）+ 右箭头/「查看收款码」；或改成紧凑胶囊按钮（☕ + 动作文案）。
- Suggested：clarify + layout

**[P1] 打赏卡视觉权重压过主标题**
- What：min-height:260px + 52px emoji 的视觉重量超过「永久免费」主标题。
- Why：打赏是次要动作却占据主要权重，读者注意力先落在卡片而不是核心价值主张。
- Fix：压缩到按钮级尺寸（高约 56–64px，或紧凑卡片 ≤160px），emoji 降到 24–28px，让标题成为视觉锚点。
- Suggested：layout

**[P1] 首屏主 CTA 损坏**
- What：hero「下载」链接指向 /Trace-macOS.dmg，public/ 中不存在该文件。
- Why：第一屏的主操作会 404，直接阻断「下载试用」核心转化。
- Fix：放入真实 dmg 文件，或暂时隐藏/替换下载链接。
- Suggested：harden

**[P2] 收款码弹窗可达性**
- What：打开时焦点不进入弹窗、Tab 可逃出（无焦点陷阱）、关闭后焦点不归还触发按钮；`<p>` 嵌套在 `<button>` 内是无效 HTML（应为 span）；弹窗缺少「打开支付宝扫一扫」引导。
- Why：键盘/读屏用户难以完成打赏；普通用户看到二维码也可能犹豫。
- Fix：打开时聚焦弹窗、关闭归还焦点；p→span；加一行小字引导。
- Suggested：harden

**[P2] 打赏区文案密度**
- What：说明段落是一整块长文本且标点缺失（「…变得更好」无句号），混合产品动机、功能局限、反馈邀请、bug 报告。
- Why：决策点堆文本增加认知负担，稀释「请喝咖啡」这一唯一动作。
- Fix：拆句/精简——动机一句、反馈邀请一句，突出打赏 CTA。
- Suggested：clarify

### Persona Red Flags

- **Jordan（初次来访）**：打赏卡无动作暗示 → 不会点击，也不知道点击后会看到什么；导航「支持项目」语义歧义。
- **Casey（移动端）**：竖屏 360px 宽、260px 高的打赏卡占据大半个屏，弱化标题；下载 CTA 在顶部拇指区外。优点：打赏点击区域够大。
- **Riley（边界测试）**：下载按钮 404；「即将上线」带 aria-disabled 却无禁用的视觉行为；弹窗无焦点陷阱、焦点不归还。

### Minor Observations

- 导航「支持项目」可改为「支持」或「打赏」。
- iPadOS「即将上线」可用真正的 disabled 按钮样式明确不可点。
- `.donation-card` 建议补 `appearance: none` / `-webkit-tap-highlight-color: transparent`，保证跨平台一致。
- 功能卡片 hover（translateY + 边框色）克制到位，无需调整。

### Questions to Consider

1. 打赏区一定要是「卡片」吗？换成安静按钮 + 弹窗会不会更自信？
2. 如果点击任意位置的 ☕ 都能打开收款码，会不会比大按钮更契合页面的克制气质？
3. 「感谢每一位支持 Tracé 的创作者。」放进弹窗（扫码前看到）会不会比放在按钮上更有仪式感，按钮只留动作？
4. 「永久免费」与打赏诉求之间，是否需要一个更明确的叙事转折？
5. 下载 dmg 缺失是临时的吗？发布前必须放真实安装包。
